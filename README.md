## 🏆 Portafolio de Startups Incluidas en este Repositorio

Cada Startup opera de manera independiente mediante enrutamiento limpio (`?project=...` o ruta directa):

### 1. 🏦 CardPay FinTech Leader — Core Bancario, Ledger & Buró de Crédito (`?project=fintech`)
* **Valuación Comercial:** $50,000 USD
* **Características Principales:**
  * **Consulta en Vivo en Padrón TSE y Ministerio de Hacienda CR:** Búsqueda en tiempo real de personas reales por Nombre y Apellidos o Número de Cédula (`/api/fintech/bureau-lookup`), verificando identidad legal y morosidad/omisión tributaria oficial.
  * **Core Ledger de Partida Doble (ACID):** Contabilidad bancaria inmutable con hash criptográfico HMAC-SHA256.
  * **Bóvedas Multidivisa (CRC, USD, EUR):** Conversión de divisas en tiempo real y cálculo de amortización (Sistema Francés y Alemán).
  * **Enrutador Interbancario (SINPE Móvil, SEPA Instant, FedWire):** Generador de mensajes Open Banking JSON e ISO 20022 XML.
  * **Ejecutivo IA & Control Dual (Maker-Checker):** Director Financiero IA con firma de autorización gerencial obligatoria.

## 🛠️ Instalación y Despliegue Rápido

```bash
# 1. Instalar dependencias
npm install

# 2. Iniciar servidor en modo desarrollo (Puerto 3000)
npm run dev

# 3. Compilar para producción
npm run build
npm start
```
